# Cindy 在学习机器学习

14 篇机器学习可视化文章。题目来自 [MLU-Explain](https://mlu-explain.github.io/)，交互重新写过。第一篇是 **Train, Test, and Validation Sets**：猫和狗、体重和毛量、可拖动的逻辑回归。

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://127.0.0.1:4321](http://127.0.0.1:4321)。

登录：`xinyi00f@outlook.com` / `cindy`。也可以点「访客进入」。

中英切换、亮暗色都在顶栏。

## 文章

训练/验证/测试集、神经网络、几率均等、逻辑回归、线性回归、强化学习、ROC & AUC、交叉验证、精确率与召回率、随机森林、决策树、偏差–方差权衡、双重下降。
