# Cindy's Digital Garden

Cindy 自学机器学习时的可视化笔记。题目来自 [MLU-Explain](https://mlu-explain.github.io/)，版式是黑白留白的个人页。

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://127.0.0.1:4321](http://127.0.0.1:4321)。

登录：`xinyi00f@outlook.com` / `cindy`。也可以点「访客进入」。

## 文章

神经网络、几率均等、逻辑回归、线性回归、强化学习、ROC & AUC、交叉验证、训练/验证/测试集、精确率与召回率、随机森林、决策树、偏差–方差权衡、双重下降。
